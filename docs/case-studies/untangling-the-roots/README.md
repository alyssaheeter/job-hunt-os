# Untangling the Roots

Case study: turning a 329-person Ancestry export into a verified, people-first knowledge graph, and finding 30 ancestors the tree had silently lost.

- [Read the case study (Markdown)](untangling-the-roots.md)
- [Standalone HTML version](untangling-the-roots.html) (download and open locally, or serve via GitHub Pages)

All data is anonymized: counts only, no real names and no living people.
